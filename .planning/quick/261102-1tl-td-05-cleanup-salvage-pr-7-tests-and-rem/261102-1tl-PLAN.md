From server/projectsDatabase.py:
- createProject(client, projectName, projectId, description, creatorUserId) returns the serialized project; creator becomes the only member. All four fields must be non-empty strings, otherwise InvalidProjectInput whose message is the parameter name (for the creator that is the literal string creatorUserId).
- queryProject(client, projectId) returns the serialized dict or None for an unknown id; raises InvalidProjectInput("projectId") for a non-string or empty id.
- getUserProjects(client, userId) returns full serialized projects (including `users`) sorted by projectId; raises InvalidProjectInput("userId") for a non-string or empty id.
- addUser(client, projectId, userId) is idempotent; raises ProjectNotFoundError for an unknown project and for a non-string projectId OR userId.
- assertProjectMember(client, projectId, userId) raises NotAHouseholdMemberError for any non-string id.
- Serialized project shape: projectId, projectName, description, users.

From server/usersDatabase.py:
- DB_NAME, USERS_COLLECTION ("Users"), addUser(client, username, userId, password), login, joinProject(client, userId, projectId) returns None, getUserProjectsList(client, userId).
- getUser and UserNotFoundError do NOT exist on main.
- Membership lives only in the project's `users` list. joinProject never writes the user document, so its `projects` field stays [].

Routes on main:
- POST /create_project requires, in this check order: projectName, projectId, description, userId. 201 {"project": {...}}.
- POST /join_project requires userId then projectId. 200 {"userId", "projectId"}.
- POST /get_user_projects_list requires userId. 200 {"projects": [...]}. No userId echo.
- POST /get_project_info requires projectId then userId. 200 {"project": {...}}.

Fixtures from conftest.py: `mongo` seeds project H1 with users alice and bob and creates NO documents in Users. `api` is the Flask test client with app.testing on, so an unhandled exception in a route propagates into the test as that exception rather than a 500 response.
